Contexto específico

Prompt engineering en la práctica

Consiste en diseñar contexto, instrucciones, ejemplos, restricciones y criterios para obtener resultados útiles y repetibles de un modelo.

01

Ejemplo

Solicitar un análisis con fuentes, formato y reglas de revisión.

02

Confusión común

No se reduce a encontrar una frase secreta.

03

Criterio

Evalúa consistencia, precisión, seguridad y utilidad.
