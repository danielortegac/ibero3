Curso para Crear Agentes de IA con Codex y Antigravity

Aprende a dirigir Codex, Google Antigravity y Goatify para construir agentes y automatizaciones que ejecuten investigación, contenido, ventas, administración, operaciones y tareas digitales repetitivas. No necesitas programar para empezar.

De pedir respuestas a delegar trabajo

No vienes a coleccionar prompts. Vienes a construir agentes que ejecutan trabajo.

La certificación está diseñada para personas de cualquier profesión que quieran automatizar tareas digitales sin convertirse en desarrolladores. Partimos de un proceso real y lo transformamos en un sistema con objetivo, contexto, herramientas, memoria/estado, loop, criterios de parada, pruebas, seguridad y supervisión humana.

Codex

Agentes para ejecutar trabajo, construir herramientas, analizar, documentar, probar y automatizar.

Antigravity

Orquestación de agentes, Projects, subagentes, archivos, terminal, navegador y tareas programadas.

Goatify

CRM, agenda, formularios, mail, AI Sellers, docs y operación conectada.

Human-in-the-loop

Aprobación, límites, trazabilidad, revisión y escalamiento cuando la decisión lo exige.

Construyes un sistema que trabaja contigo.

El resultado no es “un bot”. Es un proceso delegable y verificable que puede trabajar con archivos, web, formularios, CRM, documentos, tareas, código o contenido según tu contexto.

1. Define

Trabajo, entradas, salidas, límites y responsables.

2. Orquesta

Agentes, subagentes, tools, files, browser y acciones.

3. Prueba

Casos normales, bordes, fallas, handoff y calidad.

4. Automatiza

Loops, tareas programadas, métricas y mejora continua.

Metodología

Cuatro días para pasar de una tarea repetitiva a una automatización agentic verificable.

Cada día combina explicación, demostración, laboratorio y una evidencia. El proyecto puede ser de marketing, ventas, administración, investigación, educación, operaciones, consultoría, finanzas, contenido o productividad personal/profesional.

Temario oficial

4 días · 4 laboratorios · 4 evidencias · 1 automatización funcional

Codex y Antigravity no son un “bonus”: son el núcleo práctico del programa, conectados con Goatify y el resto del stack IBERO.

Día 1 · Diseña el trabajo antes del agente

LAB

Mapa de tareas repetitivas, valor, riesgo, frecuencia, entradas/salidas, definición de éxito, contexto y límites. Se introduce la progresión Prompt → Workflow → Loop → Agent.

Evidencia: Mapa de automatización + Agent Brief.

Día 2 · Codex: delegación, skills, automatización y construcción

LAB

Codex como centro de agentes para ejecutar tareas end-to-end, trabajar en paralelo, usar Skills, automatizar trabajo repetitivo, analizar información, generar artefactos y construir herramientas ligeras con pruebas y documentación.

Evidencia: Agente/automatización en Codex + evidencia de pruebas.

Día 3 · Antigravity: orquestación, browser, terminal y subagentes

LAB

Projects, múltiples agentes, subagentes, archivos, comandos, navegador, tareas programadas, skills/MCP, artifacts y control de permisos. Se diseña un workflow que combine investigación, acción y verificación.

Evidencia: Workflow en Antigravity + mapa de orquestación.

Día 4 · Sistema conectado: Goatify + Codex + Antigravity

LAB

Integración con CRM, forms, agenda, mail, AI Sellers, documentos y procesos; human-in-the-loop, guardrails, test harness, logs, métricas, scheduled workflows y plan de mejora.

Evidencia: Proyecto Final: agente funcional conectado a un proceso real.

Preguntas frecuentes

¿Necesito saber programar?

No. Se comienza con procesos, agentes y herramientas visuales. Codex puede ayudarte a construir o modificar componentes cuando sea necesario, y se enseña a supervisar el resultado.

¿Solo sirve para negocios?

No. Puedes automatizar investigación, educación, marketing, ventas, administración, operaciones, consultoría, contenido y tareas profesionales repetitivas.

¿Qué papel tienen Codex y Antigravity?

Codex se utiliza para agentes de ejecución, construcción, análisis, documentación y automatización. Antigravity se utiliza para orquestar agentes, proyectos, subagentes, archivos, terminal, navegador y tareas programadas.

¿Qué construyo al final?

Una automatización agentic funcional conectada a un proceso real, acompañada de pruebas, documentación, guardrails, handoff humano y una métrica de impacto.
